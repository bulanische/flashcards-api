# Flashcards API

Backend API и веб-интерфейс для изучения иностранных слов с помощью карточек. Проект развивается в сторону приложения в стиле Anki с языковыми колодами, повторением карточек и сохранением прогресса пользователя.

## Возможности

- Регистрация и JWT-аутентификация пользователей.
- Управление языками, колодами и карточками.
- Проверка прав доступа и бизнес-валидация данных.
- Повторение карточек в случайном порядке и случайном языковом направлении.
- Сохранение результатов ответов и прогресса повторения.
- Главная страница приложения и интерфейс повторения карточек на HTML, CSS и JavaScript.
- Автоматические тесты API.

## Технологический стек

- Python 3.11, FastAPI
- SQLAlchemy 2.0, PostgreSQL, asyncpg
- Pydantic v2, Alembic
- FastAPI Users, JWT
- Docker / Docker Compose
- pytest, pytest-asyncio, HTTPX
- HTML, CSS, JavaScript

## Запуск

Требуются Python 3.11, Docker Desktop и Git.

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл `.env` с настройками PostgreSQL и секретным ключом приложения.

Запустите проект:

```bash
./start.sh
```


Применение миграций:

```bash
alembic upgrade head
```

## Интерфейс и API

После запуска приложения:

- Главная страница: http://localhost:8000/
- Swagger UI: http://localhost:8000/docs
- OpenAPI: http://localhost:8000/openapi.json

Основные группы API: `/auth`, `/languages`, `/decks`, `/cards`, `/review`.

## Тестирование

```bash

```

## Статус проекта

Реализованы авторизация, CRUD-операции, работа с PostgreSQL, API повторения карточек, сохранение результатов ответов и главная страница с веб-интерфейсом.

В планах — подключение интерфейса повторения к API, доработка повторения ошибочных ответов, развитие алгоритма интервального повторения и добавление статистики обучения.
