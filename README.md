# Flashcards API

Backend API для изучения иностранных слов с помощью карточек.

Проект представляет собой основу приложения в стиле Anki: пользователь создаёт языковые колоды, добавляет карточки и работает с ними через REST API.

## Возможности

### Пользователи и авторизация

* регистрация пользователя;
* авторизация по email и паролю;
* JWT-аутентификация;
* получение данных текущего пользователя;
* изоляция пользовательских данных.

### Языки

* просмотр доступных языков;
* системные языки, доступные всем пользователям;
* создание пользовательских языков;
* удаление собственных языков;
* защита от удаления языка, который используется в колодах или карточках.

### Колоды

* создание колоды из двух языков;
* просмотр собственных колод;
* изменение названия колоды;
* удаление колоды;
* автоматическое удаление карточек при удалении колоды;
* проверка доступности языков;
* защита от дублирующихся колод.

### Карточки

* создание карточек;
* просмотр собственных карточек;
* фильтрация карточек по колодам;
* изменение карточки;
* перенос карточки в другую совместимую колоду;
* удаление карточки;
* проверка соответствия языков карточки языкам колоды;
* защита от дублирующихся карточек.

## Запуск проекта

### Требования

Необходимы:

* Python 3.11
* Docker Desktop
* Git

### Установка

Клонируйте репозиторий и перейдите в директорию проекта:

```bash
cd cards
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его:

```bash
source venv/Scripts/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

### Переменные окружения

Создайте файл `.env`:

```env
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=cards
POSTGRES_SERVER=localhost
POSTGRES_PORT=5432

DATABASE_URL=postgresql+asyncpg://${POSTGRES_USER}:${POSTGRES_PASSWORD}@${POSTGRES_SERVER}:${POSTGRES_PORT}/${POSTGRES_DB}

SECRET_KEY=your-secret-key
```

Для реального использования необходимо заменить `SECRET_KEY` на собственное секретное значение.

### Запуск

Проект можно запустить с помощью:

```bash
./start.sh
```

Скрипт:

1. запускает Docker Desktop;
2. ожидает запуска Docker Engine;
3. запускает контейнер PostgreSQL;
4. запускает FastAPI через Uvicorn.

Для остановки проекта:

```bash
./stop.sh
```

## База данных

PostgreSQL запускается в Docker-контейнере.

Основная база данных проекта:

```text
cards
```

Миграции выполняются с помощью Alembic.

Применить существующие миграции:

```bash
alembic upgrade head
```

Создать новую миграцию после изменения моделей:

```bash
alembic revision --autogenerate -m "description"
```

Проверить текущую миграцию:

```bash
alembic current
```

## API

После запуска приложения Swagger UI доступен по адресу:

```text
http://localhost:8000/docs
```

Также доступна OpenAPI-схема:

```text
http://localhost:8000/openapi.json
```

Основные группы API:

```text
/auth
/languages
/decks
/cards
```

Для защищённых endpoints необходимо сначала авторизоваться и передавать JWT access token.

## Тестирование

Проект использует:

- `pytest`;
- `pytest-asyncio`;
- `httpx`.

Тестовая инфраструктура находится в разработке.

Запуск тестов:

```bash
pytest
```

Тесты постепенно покрывают:

* регистрацию и авторизацию;
* работу с языками;
* работу с колодами;
* работу с карточками;
* проверку прав доступа;
* бизнес-валидацию;
* обработку ошибок API.

## Работа с зависимостями

Прямые зависимости проекта находятся в:

```text
requirements.in
```

Зафиксированные версии всех зависимостей находятся в:

```text
requirements.txt
```

После изменения `requirements.in` файл `requirements.txt` пересобирается с помощью:

```bash
pip-compile
```

Установка зафиксированных зависимостей:

```bash
pip install -r requirements.txt
```
